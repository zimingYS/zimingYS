## 🚀 重点项目

### 🐱 [UpCat · 升学猫](https://github.com/zimingYS/UpCat)

**智慧校园升学就业系统** · `v1.4.0`

面向大学生、就业指导教师与平台管理员的一站式升学就业平台，围绕自我认知、方向选择、计划制定、求职升学与去向确认，整合智能咨询、知识检索、职业规划和就业数据分析。

**技术栈：** Rust · Axum · Tokio · SQLx · Vue 3 · TypeScript · Python · FastAPI · LangGraph · PostgreSQL · pgvector · Redis

**主要实践：**
- 基于 LangGraph 实现 AI 多智能体意图路由、工具调用与执行轨迹展示。
- 基于 pgvector 构建 RAG 检索，支持知识来源引用与 SSE 流式对话。
- 实现简历解析、双向人岗匹配、WebSocket 实时通知与数据看板。
- 使用 Docker Compose、GitHub Actions 与 GHCR 完成容器化交付。

### 🌍 [CenturyJourney · 世纪之旅](https://github.com/zimingYS/century_journey)

**基于 Rust + Bevy 的体素生存游戏**

探索地质、气候与世界模拟的体素世界，重点关注地形生成、游戏运行时与模块化工程架构。

**技术栈：** Rust 2024 · Bevy · Cargo Workspace

**主要实践：**
- 使用 Cargo Workspace 拆分 core、sim、world、runtime、render、game 与 app。
- 隔离领域逻辑、世界数据与 Bevy ECS / 渲染层。
- 围绕区块、体素、世界生成和玩家改动构建基础系统。

<sub>个人长期项目 · 早期原型阶段</sub>
