## 👋 About Me

你好，我是 **张訾铭（zimingYS）**，主要专注于 **Rust 后端开发与全栈应用实践**。

- 🦀 使用 **Rust** 和 **Axum / Tokio / SQLx** 构建异步后端与业务服务。
- 🖥️ 使用 **Vue 3、TypeScript** 开发 Web 应用，也有 React 项目实践。
- 🤖 使用 **Python、FastAPI、LangGraph** 探索 AI 工作流、智能体编排与 RAG 应用。
- 🗄️ 关注 PostgreSQL、Redis、数据库设计与服务边界。
- ⚙️ 重视 Docker、GitHub Actions、自动化测试和可复现交付。

我更喜欢从一个真实问题出发，先梳理需求与边界，再通过清晰的架构、可验证的实现和持续迭代把它落地。
